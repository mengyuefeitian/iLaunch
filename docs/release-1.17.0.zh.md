# iLaunch 1.17.0 更新说明

- **内置五指手势**：不用 BetterTouchTool。五指捏拢打开 iLaunch，张开收起 iLaunch 或显示桌面；显示桌面后，第一次捏拢恢复窗口，第二次才打开 iLaunch。保留 macOS 的四指轻扫。iLaunch 的「设置 → 通用 → 动画」可关闭五指手势。
- **F4 与快捷键**：新安装默认用 F4，按键方式随功能键模式而定，已有自定义绑定会保留。支持直接录入单键，并新增「设置 → 通用 → 启动 → 全局快捷键 → 强制绑定 F4」，可在键盘重连、系统动作抢占 F4 等情况下重新应用映射。
- **窗口和交互**：支持在全屏应用上唤起，切换桌面时收起。修正设置窗焦点、图标拖动跨页、文件夹与搜索的联动。应用启动改为异步处理，文件夹和翻页动画也一并调顺。

**启用五指手势前**，请在 macOS 的「系统设置 → 触控板 → 更多手势」同时关闭 **App（拇指和其他三指捏拢）** 与 **显示桌面（拇指和其他三指张开）**。详见[手势设置说明](https://github.com/MarchiSteve/iLaunch/blob/fix/fullscreen-spaces-folder-backdrop/docs/trackpad-gestures.zh.md)。

已在 Apple 芯片 Mac 上编译和启动 1.17.0，主要手势、F4 和文件夹流程已在本机验证。全量 SwiftPM 测试受本机工具链限制未完成。「强制绑定 F4」在不同键盘和 Fn 模式下仍需实机验证。
