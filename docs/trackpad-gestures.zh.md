# 内置五指手势

在 iLaunch 的「设置 → 通用 → 动画」中，可开启或关闭「五指捏拢和张开」。

启用时，在「系统设置 → 触控板 → 更多手势」中同时关闭以下两项，以免系统动作与 iLaunch 冲突：

- App（捏拢拇指和其他三指）
- 显示桌面（张开拇指和其他三指）

四指上下、左右轻扫由 macOS 处理，可在系统设置中按喜好配置。

| 当前状态 | 五指动作 | 结果 |
| --- | --- | --- |
| 普通应用窗口 | 捏拢 | 打开 iLaunch |
| iLaunch 正在显示 | 张开 | 收起 iLaunch |
| 普通应用窗口 | 张开 | 显示桌面 |
| 已用手势显示桌面 | 捏拢 | 恢复原窗口，再捏一次才打开 iLaunch |

五指指总共五个触点，通常为拇指加另外四指。一次触摸只触发一次，请松开手指后再做下一次。重复张开会保持显示桌面。

## 快捷键

新安装默认使用 F4，已有自定义绑定会保留。设置支持录入单键。若原 F4 功能仍触发，或外接 Apple 键盘重连后按键失效，可在「设置 → 通用 → 启动 → 全局快捷键」点击「强制绑定 F4」，重新注册并应用映射。是否需要 Fn 取决于功能键模式。第三方键盘发送的系统键和其他快捷键工具的占用可能影响重新绑定。

## 实现与验证

触控数据接口参考 MIT 许可的 [macos-gesture-launcher](https://github.com/okruts/macos-gesture-launcher)，原许可证位于 `Resources/GestureLauncher-LICENSE.txt`，安装包中也包含许可证。手势识别使用苹果的 MultitouchSupport 私有接口，显示桌面使用 CoreDockSendNotification，系统升级后可能需要适配。

已在 Apple 芯片 Mac、macOS 27.0.1 和外接 Magic Trackpad 上验证主要手势流程。曾通过独立检查验证四触点不触发识别。新版通过编译和本机启动校验。全量 SwiftPM 测试受本机工具链限制，未能完成。多设备、热插拔和不同键盘模式仍需补充验证。
